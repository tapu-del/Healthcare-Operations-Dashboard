# Healthcare-Operations-Dashboard


## About the Project
This project is an interactive Excel dashboard built to analyze hospital operations, patient flow, and bed occupancy. The goal was to uncover insights into which departments are busiest and how shifts impact patient admissions.

## Tools & Skills Used
* Microsoft Excel
* Data Cleaning & Preparation
* PivotTables & PivotCharts
* Interactive Slicers
* Dashboard Design

## Key Metrics Analyzed
* **Department Busyness:** Identified which departments (ICU, General, Surgery) have the highest occupied beds.
* **Shift Analysis:** Analyzed Day vs. Night shift admissions using a Pie Chart.
* **Interactive Filtering:** Added a Slicer to filter the entire dashboard by hospital city.
